# SafeExit-RL
## Adaptive Fire Evacuation Guidance Using Reinforcement Learning

We propose an RL-based evacuation guidance system that dynamically adjusts exit directions as fire hazards, blocked corridors, and crowd congestion evolve. The agent learns to balance evacuation time, toxic exposure, and congestion using noisy, delayed sensor observations. We will compare its performance against shortest-path and rule-based guidance policies in a simulated building.
